# Lista de control antes de publicar videos y proyectos

## Repositorio
- [ ] Es público y se abre desde una ventana incógnita.
- [ ] README explica motivación, método, resultados y limitaciones.
- [ ] Las pruebas automáticas del último commit pasan.
- [ ] No hay secretos, tokens ni contenidos de terceros sin licencia.
- [ ] El enlace público del código está presente en las descripciones.

## Vídeo
- [ ] Matemática revisada: 77 = 9² − 2² = (9 − 2)(9 + 2) = 7 × 11.
- [ ] RSA se describe correctamente: clave pública (n,e), no solo n.
- [ ] Se aclara que el algoritmo de Fermat no permite romper RSA moderno con facilidad.
- [ ] Voz clara, pausas suficientes, sin palabras cortadas.
- [ ] Subtítulos sincronizados y legibles en el móvil.
- [ ] No hay contenido tapado por botones o controles de las plataformas.
- [ ] Portada, título, descripción, enlaces y atribuciones revisados.
- [ ] Preview revisado en el teléfono antes de publicarlo.

## Después de publicar
- [ ] Registrar enlaces permanentes a YouTube y TikTok en el episodio.
- [ ] Versionar cambios de documentación y resultados.
- [ ] Registrar preguntas de audiencia, erratas y futuras mejoras.
- [ ] Evaluar qué aprendí explicándolo y qué todavía no domino.
